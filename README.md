# B站弹幕长句发送（隐形快速版）

一个 Tampermonkey 用户脚本：在 B 站直播间输入框里**写超过 20 字的长弹幕**，回车后自动按标点切成多条、并发发出去。
输入框保持 B 站原样（默认不显示任何多余面板），超出显示上限的字在后台继续保留。

- 版本：**7.3.0**
- 适用：`https://live.bilibili.com/*`（桌面版 Edge / Chrome + Tampermonkey 5.x）
- 依赖：无（`@grant none`，直接用页面内 fetch + cookie）

## 功能

| 能力 | 说明 |
|---|---|
| 长弹幕自动分条 | 按 `，。！？、；：…` 等标点切分，每条不超过 20 字（B 站硬上限） |
| 影子缓冲 | 真正的文本存在脚本里（默认上限 200 字），输入框只镜像显示前约 40 个汉字 |
| 并发发送 | 批内并发（默认间隔 120ms、±20% 抖动），批次串行，不会把两段话插在一起 |
| 失败留档 | 任何没发出去的条目都进「最近被吞」列表，并把失败句还原到输入框（≥3 条才全部还原） |
| 屏蔽词提示 | 命中本地词库（默认 17 词）时顶部弹一条 5 秒自隐的提示条，不当场拦截 |
| 面板隐形 | 默认不渲染面板，只有右下角半透明 `⋯` 才打开设置 |

## 安装

### 方式 A：从 GitHub 安装（推荐，公开仓库时可用）

1. 装 Tampermonkey；
2. 打开仓库里的 `bili-danmaku-split.user.js` 的 **Raw** 链接：
   `https://raw.githubusercontent.com/LikeEphemeralAurora/bili-danmaku-split/main/bili-danmaku-split.user.js`
3. Tampermonkey 会弹出安装页 → 点【安装】。

> 私有仓库的 Raw 链接对别人不可用（需要登录），要分享给别人请把仓库设为 Public，或改用下面的「方式 B」。

### 方式 B：本地文件安装（仓库私有 / 离线也能用）

1. 下载 `bili-danmaku-split.user.js`；
2. Tampermonkey 面板 → 左上 **+**（新建脚本）→ 全选删掉模板 → 粘贴文件内容 → `Ctrl+S`；
3. 打开直播间，按 `F5` 刷新。

> 直接双击 `.user.js` 文件**不会**安装（`file://` 不触发 TM），必须走「新建脚本 + 粘贴」。
> 也可以用本地 HTTP 起一个临时服务再打开：`python -m http.server 8777` → 浏览器访问 `http://127.0.0.1:8777/bili-danmaku-split.user.js`。

## 使用

1. 打开任意直播间，点 B 站输入框，正常打字（可超过 20 字）；
2. 超过显示上限时会提示一次「后面的字仍在后台保留」；
3. `回车` 发送（按标点切分、并发发出）；
4. `Esc` 清空；`←/→/Home/End` 可移动光标；
5. 右下角 `⋯` 打开设置：每条上限、并发间隔、字数上限、输入框加高、自动补发、屏蔽词、最近被吞。

### 设置项

| 键 | 默认 | 说明 |
|---|---|---|
| `limit` | 20 | 每条字数，1–20（发送时硬截 20，保证符合 B 站上限） |
| `gapMs` | 120 | 并发间隔（毫秒，±20% 抖动） |
| `typeLimit` | 200 | 后台缓冲允许的总字数 |
| `mirrorWidth` | 80 | 镜像到输入框的显示宽度（中文算 2，约 40 汉字） |
| `boxExtra` | 0 | 输入框额外加高像素，0 = 不改 B 站原样 |
| `retry` | true | 失败后 3.5 秒后台补发一次 |
| `blockGuard` | true | 命中屏蔽词时弹提示条 |

## 已知限制

- B 站输入框本身只能显示约 40 个汉字，**后面的字在框里看不到**（但在后台保留、照样会发出去）——这是 B 站前端限制，不是脚本吞字。
- 没有原版「B站直播聊天室弹幕发送增强 v0.4.6」的屏蔽词库，只有本地默认 17 词，可自行编辑。
- 同一浏览器里**只启用一个版本**；多个版本会抢同一个输入框（重复发、字数错乱）。
- 手机浏览器基本不可用。
