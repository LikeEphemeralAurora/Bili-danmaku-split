# B站弹幕长句发送（隐形快速版）

一个 Tampermonkey 用户脚本，解决 B 站直播弹幕框「只能写 20 字」的问题：**长句写在面板的写作框里，一次点发送，自动按标点切成多条依次发出去**。
默认**完全不干扰 B 站原生输入**——回车、粘贴、输入法都和没装脚本一样。

- 版本：**8.0.2**
- 适用：`https://live.bilibili.com/*`（桌面版 Edge / Chrome + Tampermonkey 5.x）
- 依赖：无（`@grant none`，直接页面内 fetch + cookie）

## 两种模式

| 模式 | 行为 | 适用 |
|---|---|---|
| **兼容**（默认） | 完全不监听键盘与粘贴。B 站框原样输入（≤20 字），回车由 B 站自己发；长句用面板里的「写作框」，`Ctrl+Enter` 或点「发送」自动分条 | 所有人，最稳 |
| 接管（实验） | 脚本自己维护缓冲区并镜像到 B 站框，可在框里连续输入超过 20 字 | 想「框里直接写长句」且能接受输入法副作用 |

> 接管模式与中文输入法天然冲突：中文状态下第一下回车会被输入法吃掉去上屏候选（表现为"要按两次回车"），搜狗英文模式下 Shift 提交候选也可能被拦。所以默认是兼容模式。

## 功能

| 能力 | 说明 |
|---|---|
| 长句自动分条 | 按 `，。！？、；：…` 等标点切分，每条不超过 20 字（B 站硬上限） |
| 写作框 | 面板内独立输入框，随便写多长，`Ctrl+Enter` 发送 |
| 批次串行 + 批内并发 | 两段话不会插在一起；每条约 120ms 错开（可调、±20% 抖动） |
| 失败留档 | 没发出去的条目进「最近被吞」列表，并把失败句还原到输入框（≥3 条才全部还原） |
| 屏蔽词提示 | 命中本地词库（默认 17 词）时顶部弹一条 5 秒自隐提示条；可在面板编辑词库 |
| 面板隐形 | 默认不渲染面板，只有右下角半透明 `⋯` 打开设置 |
| 输入框加高 | `boxExtra` 0–120px，自己试 B 站前端能不能接受（撑太高可能盖住按钮） |

## 安装

### 方式 A：从 GitHub 安装（仓库为 Public 时可用）

1. 装 Tampermonkey；
2. 打开 Raw 链接：
   `https://raw.githubusercontent.com/LikeEphemeralAurora/Bili-danmaku-split/main/bili-danmaku-split.user.js`
3. Tampermonkey 弹出安装页 → 点【安装】。

> **私有仓库的 Raw 链接对别人不可用**（要登录）。要分享给别人请把仓库设为 Public，或直接用方式 B。

### 方式 B：本地文件安装（私有仓库 / 离线也能用）

1. 下载 `bili-danmaku-split.user.js`；
2. Tampermonkey 面板 → 左上 **+** → 全选删掉模板 → 粘贴内容 → `Ctrl+S`；
3. 打开直播间 `F5`。

> 双击 `.user.js` **不会**安装（`file://` 不触发 TM）。若想走自动安装页，可以在文件目录里起
> `python -m http.server 8777`，再让浏览器访问 `http://127.0.0.1:8777/bili-danmaku-split.user.js`。

## 使用

### 兼容模式（默认）

1. 打开直播间，点 B 站输入框，正常打字（最多 20 字），**回车即发**——完全是 B 站原行为；
2. 想发更长的：点右下角 `⋯` → 在「写作框」里写 → `Ctrl+Enter` 或点「发送」；
3. 写作框里可以随便长，脚本会按标点切分，一条条发出去，发完 toast 汇报「已发 X 条」；
4. `Ctrl+V` / Ditto（`Ctrl+``）粘贴照旧。

### 接管模式（可选）

面板「输入模式」选「接管」→ 页面自动重载后，B 站框会变成镜像显示（能看到约 40 汉字），
你实际写入的字存在脚本缓冲区里，上限 `typeLimit`（默认 200）。回车发送，`Esc` 清空。

### 设置项

| 键 | 默认 | 说明 |
|---|---|---|
| `mode` | `compat` | `compat` 兼容 / `shadow` 接管 |
| `limit` | 20 | 每条字数，1–20（发送时硬截 20） |
| `gapMs` | 120 | 并发间隔（毫秒，±20% 抖动） |
| `typeLimit` | 200 | 接管模式下缓冲区允许的总字数 |
| `mirrorWidth` | 80 | 接管模式下镜像到输入框的显示宽度（中文算 2） |
| `boxExtra` | 0 | 输入框额外加高像素，0 = 不改 B 站原样 |
| `retry` | true | 失败后 3.5 秒后台补发一次 |
| `blockGuard` | true | 命中屏蔽词时弹提示条（不拦截） |

## 已知限制

- B 站单条弹幕 20 字是服务端硬限制，无法绕过，只能切分。
- 接管模式在中文输入法下会出现「双回车」与「Shift 不落字」；这是输入法行为，脚本无法可靠区分「用户要提交候选」与「用户要发送」。
- 同一浏览器里**只启用一个版本**；多个版本会抢同一个输入框（重复发、字数错乱）。
- 发太快会被限速（`10031`），脚本会退避重试一次并留档；仍失败请等几十秒。
- 手机浏览器基本不可用。

## 版本历史

- **8.0.2** 兼容模式不再拦 `Enter`（回车完全交还 B 站），长句统一走写作框
- **8.0.1** 兼容模式不再拦截 `paste`（恢复 `Ctrl+V` 与 Ditto）
- **8.0.0** 默认改为「兼容模式」；新增写作框；接管模式降级为实验选项
- **7.6.0** 接管逻辑改用 `beforeinput`（修复空格/退格/Shift 符号失效）
- **7.5.1** 成对符号（`“”`/`（）`）光标落点修正；光标位置与镜像解耦
- **7.4.0** 发送成功后清空输入框（用原生 setter 同步，破解受控组件回填）
- **7.3.0** 增加输入框加高开关（`boxExtra`）
- **7.2.0** 每条上限 1–20 且发送硬截 20；镜像后自动滚动到底；失败按数量决定还原范围；被吞列表可滚动
- **7.1.0** 所有失败都留档并还原到输入框（不再只认「被吞」错误码）
- **7.0.0** 影子缓冲 + 镜像显示（框里可写超过 20 字）
- **6.2.0** 命中提示条、可编辑屏蔽词、最近被吞列表
- **6.1.0** 发送队列（批次串行、批内并发）
- **6.0.0** 整份重写：隐形面板、并发投递、失败补发
- **1.x** 最初版本：本地屏蔽词库 + 命中二次确认
